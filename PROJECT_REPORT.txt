  * Hex dump with 16-byte rows, per-layer color tinting
  * Expandable/collapsible protocol layers with hover highlight
  * Display filter input (searches protocol, source, destination, packet number)
  * Start/Stop/Clear capture controls
  * Hover row → highlights Ethernet frame in hex viewer
  * Select row → expands all layers and highlights full frame
- src/components/PacketSniffer.css
  * Styles for all sniffer sub-components

Files Modified:
- src/App.tsx
  * serializeAndCapturePacket() — backbone of sniffing pipeline
  * generateHexDump() — random byte arrays per protocol
  * buildLayers() — packet field construction (Ethernet II, IPv4, ICMP/DNS/HTTP)
  * handleTriggerPing() — now calls serializeAndCapturePacket() on success/failure
  * handlePlaySimulation / handleFireEvent — both capture packets
  * window.triggerTestPacket (test API for manual packet injection)
  * capturedPackets state (capped at 2000, passed to PacketSniffer)

Backend Logic in App.tsx:
- generateHexDump(protocol): ICMP=98B, DNS=76B, HTTP=523B, default=60B
- buildLayers(protocol, source, dest):
  * Base: Ethernet II (Dst MAC, Src MAC, Type=0x0800) + IPv4
  * ICMP: adds Internet Control Message Protocol (Type/Code/Checksum)
  * DNS: adds UDP (port 53) + DNS query fields
  * HTTP: adds TCP (port 80, PSH+ACK) + HTTP GET fields
  * Other: generic TCP layer
- serializeAndCapturePacket(event):
  * Generates hex bytes → ASCII bytes → layers
  * Assembles Packet object with unique ID, packet number, relative timestamp
  * Appends to capturedPackets (truncates to last 2000)
  * Called on every ping success, ping failure, simulation play, and event fire

UI Design (PacketSniffer.tsx):
- Toolbar: Start (green) | Stop (red) | Clear (gray) | Display filter | Status dot + count
- Packet List: 7-column table (No, Time, Source, Destination, Protocol, Length, Info)
  * Colored protocol chips, alternating row backgrounds
  * Hover → Ethernet frame highlight; Click → full layer expansion
- Protocol Layers: color-coded expandable rows with chevron toggle
  * Layer fields displayed as "name: value" pairs
  * Hover layer → hex bytes for that layer are highlighted
- Hex & ASCII pane:
  * 16-byte rows with Offset + hex bytes + ASCII characters
  * Per-byte tinting: each protocol layer has a unique color
  * Active highlight overrides tint (cyan #34d3eb)
  * Non-printable bytes rendered as '.'
